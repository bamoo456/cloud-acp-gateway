色系候選

四個候選，全部套在真實畫面上（web/src/preview.tsx 的 harness），因為中性色階只能對著實際的字與框判斷。四種顏色語意（ink＝互動／進行中、amber＝需要你、red＝失敗與 diff −、green＝diff +）在四個候選裡都不變；移動的是中性色階，C 與 D 另外調了那三個語意色的濃度。

Theme
APaper（現況） 暖灰紙、暖黑字。分支上現在就是這一組。
BSlate 把暖度從兩條色階裡拿掉，中性偏冷。程式碼與 diff 的紅綠會更跳。
CContrast 純白／純黑底，字近全黑全白，三個語意色加深一階才壓得住。對比最高，也最硬。
DSepia A 的暖色階再往紙的方向壓一階，語意色同步調低，三個顏色坐在紙上而不是浮在上面。
